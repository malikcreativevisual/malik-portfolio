MALIK PORTFOLIO — LOCAL PREVIEW

HOW TO OPEN (EASIEST)
1. Extract this ZIP folder somewhere on your Windows PC.
2. Double-click index.html to open it in Chrome, Edge, or Opera.
3. Use the fixed sidebar (desktop) or bottom navigation (mobile) to switch pages.
4. On Beauty/Products and Social Contents, use the arrows or dots to change videos. The center video has playback controls.

NOTES
- This is a static website; no Node.js or build step is required.
- Internet is used only to load the Outfit font from Google Fonts. If offline, a fallback font is used.
- Contact links are wired to the email, Instagram, and LinkedIn addresses from the supplied notes.
- Original supplied videos and image assets are included. Because the videos are large, the ZIP may take a little while to extract.
- Before publishing to GitHub Pages, keep the relative asset paths and upload the contents of this folder to your repository.
